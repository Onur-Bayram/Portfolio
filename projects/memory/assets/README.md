# Asset Structure

This folder is organized by usage area and theme so design files are easier to find and maintain.

- `shared/`: reusable assets that appear across themes or in the default winner flow
- `home/`: assets used only on the start screen
- `settings/`: assets used only on the settings screen
- `code-vibes/`: card art, preview images, and buttons for the Code Vibes theme
- `gaming/`: card art, winner flow assets, and buttons for the Gaming theme
- `da-projects/`: card art, winner flow assets, and buttons for the DA Projects theme
- `foods/`: card art, popup assets, winner flow assets, and buttons for the Foods theme

The build copies everything from `public/assets` into the final `dist/assets` output automatically.
